# 演示视频稿 —— 校园竞赛申报材料智能核验系统

> **时长**: 约 8–10 分钟 | **讲解人**: 产品演示


## 一、开场（30 秒）

**画面**：系统登录页

**讲解**：

> 大家好。今天演示的是一套**校园竞赛申报材料智能核验系统**——Campus Copilot。
>
> 它面向高校师生，把「竞赛通知发布 → AI 自动解析 → 学生组队申报 → 材料提交 → AI 智能核验 → 教师审核」整个流程串联在一起，大幅减少人工核对工作。
>
> 系统前端用 **Vue 3 + Element Plus + Vite** 构建，后端使用 **Spring Boot 3 + MyBatis-Plus**，AI 能力接入阿里云 **DashScope 大模型**（qwen-turbo / qwen-vl-plus）。


## 二、注册与登录（1 分钟）

**画面**：登录页 → 点击「立即注册」→ 填写注册表单 → 注册成功 → 自动跳转登录

**操作**：
1. 点击「立即注册」
2. 填写：用户名 `zhangsan`、真实姓名 `张三`、密码 `123456`
3. 注册成功，切回登录页
4. 输入 `zhangsan` / `123456`，登录

**讲解**：

> 先注册一个学生账号。系统内置三级角色——学生、教师、管理员。
> 密码使用 **BCrypt** 加盐哈希存储，登录后颁发 **JWT Token**，24 小时有效，前端通过 **Axios 拦截器**自动附加到每次请求的 Authorization 头。


## 三、侧边栏 & 仪表盘总览（30 秒）

**画面**：登录后进入仪表盘，扫一眼侧边栏和顶部指标卡

**讲解**：

> 登录后进入主界面。左侧导航栏展示所有功能入口——总览看板、通知解析、项目申报、材料检查、消息中心、审计日志。
>
> 导航栏底部是当前用户信息区，点击弹出「个人信息」和「退出登录」。
>
> 消息中心如果有未读消息，导航项会显示红色数字角标。
>
> 顶部三张指标卡实时展示项目状态、完成率和截止时间。


## 四、教师上传竞赛通知（1 分钟）

**画面**：退出当前学生账号 → 登录教师账号 → 点击「通知解析」→ 上传真实 PDF 通知文件

**操作**：
1. 退出登录（点击侧边栏底部用户名 → 退出登录）
2. 用 `teacher01` / `123456` 登录
3. 侧边栏点击「通知解析」
4. 填写标题「2026 年大学生创新创业训练计划项目申报」
5. 点击「上传通知」选择 PDF 文件
6. 点击「保存信息」

**讲解**：

> 切换到教师账号。教师登录后看到的是「我的项目」总览，可以查看所有指导项目的进度。
>
> 现在来发布一条竞赛通知。系统支持两种方式：直接粘贴通知原文，或者上传 PDF / DOCX 文件。
>
> 文件上传后存储在后端 **file_asset 表**中，以 **LONGBLOB** 格式保存，同时预留了 **storage_path** 字段，未来可平滑迁移到 **MinIO / S3 对象存储**。
>
> 保存成功后，右侧解析结果区提示「待解析」。


## 五、AI 智能解析通知（1 分钟）

**画面**：点击「智能解析」→ 等待 → 右侧出现解析结果

**操作**：
1. 点击「智能解析」按钮
2. 等待约 3–5 秒
3. 右侧展示：截止时间、适用对象、AI 解析摘要、材料要求标签

**讲解**：

> 点击「智能解析」后，系统将通知文本发送至阿里云 **DashScope** 平台，调用 **qwen-turbo 大模型**。
>
> 提示词工程告诉模型：你是一个竞赛管理专家，请从通知中提取主办方、截止时间、面向对象、关键要点和材料要求清单，并以 JSON 格式返回。
>
> 模型返回结构化数据后，系统自动：
> - 回填通知实体字段
> - 生成 **material_requirement** 记录（项目申报书、团队成员表、指导教师意见表等）
> - 写入 **agent_task_log** 审计日志，记录工具名称、输入摘要、执行结果
>
> 如果 PDF 是扫描件、无法直接提取文字，系统还会自动降级到 **qwen-vl-plus 视觉模型**，把 PDF 渲染成图片做 OCR 识别——这是双重保障机制。


## 六、学生创建项目 + 添加成员（1 分钟）

**画面**：退出教师 → 登录学生 `zhangsan` → 创建项目

**操作**：
1. 退出教师账号，登录 `zhangsan` / `123456`
2. 点击「项目申报」
3. 选择关联通知（刚刚教师发布的）
4. 填写项目名称「基于深度学习的校园智能导航系统」
5. 填写团队名称「智航队」
6. 选择指导教师「张老师」
7. 添加成员（可选）
8. 点击「创建项目」

**讲解**：

> 切换回学生账号。在「项目申报」面板中选择刚才教师发布的竞赛通知，系统会自动同步截止时间。
>
> 创建项目时，系统在 **competition_project** 表中插入项目记录，同时根据通知的材料要求，自动初始化所有 **project_material** 记录，初始状态为 pending。
>
> 项目进度由**数据库触发器**和 **Java 服务层**双重保障：只要材料状态变化，触发器 `trg_project_material_after_insert_refresh_project` 自动调用存储过程 `sp_refresh_project_progress` 重算完成率和项目状态。
>
> 创建成功后，右侧立即展示项目详情和成员管理区。队长可以随时添加或移除成员。


## 七、上传申报材料（1 分钟）

**画面**：进入材料检查面板 → 逐项上传材料文件

**操作**：
1. 点击「材料检查」
2. 逐项上传（项目申报书 DOCX、团队成员表 XLSX、指导教师意见表 DOCX）
3. 每次上传后看到完成率提升

**讲解**：

> 进入材料检查面板。左侧是材料清单，右侧是 AI 检查结果区。
>
> 逐项上传材料文件。系统支持 **PDF、DOCX、XLSX** 等常见格式。
>
> 每次上传自动**版本管理**——version_no 递增，历史版本全部保留。
>
> 可以看到，每上传一份材料，项目状态从 draft 变为 incomplete，完成率实时更新。这个进度计算由 **MySQL 触发器 + 存储过程** 实时驱动，保证数据一致性。


## 八、AI 材料智能核验（1 分钟）

**画面**：点击「运行核验」→ 等待 → 查看 AI 审核结果

**操作**：
1. 点击「运行核验」
2. 等待约 5–8 秒
3. 查看 AI 审核结果

**讲解**：

> 全部材料上传后，点击「运行核验」。
>
> 系统首先通过 **Apache Tika** 提取每个文件中的文本内容——这利用了 Tika 的 **AutoDetectParser**，可以自动识别文档格式并提取纯文本。提取结果限制在 10 万字符以内。
>
> 然后构建项目上下文——包括项目名称、团队信息、各文件提取文本——一并发送给 **qwen-turbo**，让大模型从**完整性、内容相关性、规范性**三个维度评估材料质量。
>
> AI 返回审核结果：pass（通过）/ warning（警告）/ reject（驳回），并附带详细的中文评审意见。
>
> 同时，系统自动做三件事：
> - 保存 **review_record** 审核记录
> - 写入 **agent_task_log** 审计日志
> - 如果不通过，生成 **notify_message** 通知消息推送给项目队长
>
> 这就是 AI 提效的核心——从前靠人工逐份核对，现在一键完成。


## 九、教师审核材料（1 分钟）

**画面**：切换教师 → 选择项目 → 逐项审核材料

**操作**：
1. 退出学生，登录 `teacher01`
2. 在「我的项目」点击项目
3. 进入「材料审核」面板
4. 对每项材料选择「通过」或「需修改」
5. 如果「需修改」，填写修改建议

**讲解**：

> 切换回教师账号。材料审核面板展示项目的全部材料及其审核状态。
>
> 教师可以逐项审核：通过则标记 approved，需修改则填写具体建议并标记 revision。
>
> 当教师点击「需修改」时，系统自动生成通知消息发送给学生，学生会在消息中心收到通知。
>
> 审核结果同样写入 **review_record** 表，完整保留审核轨迹。

**画面**：切换学生 → 查看消息中心 → 未读 Badge → 标记已读

**操作**：
1. 退出教师，登录 `zhangsan`

4. 看到教师审核反馈通知
5. 点击消息标记已读，或点击「全部已读」

> 学生登录后，侧边栏「消息中心」的红色角标提示有新消息。
>
> 消息列表按时间倒序展示，类型标签区分材料通知、截止提醒、系统消息。
>
> 支持「全部消息」和「仅未读」分段筛选，单击消息标为已读，也可以一键全部已读。


## 十一、审计日志（20 秒）

**画面**：点击「审计日志」→ 查看 AI 调用记录

**操作**：
1. 点击侧边栏「审计日志」
2. 查看通知解析、材料检查等 AI 调用记录
3. 筛选工具类型
4. 展开某条查看详情

**讲解**：

> 「审计日志」面板记录了每一次 AI 工具调用的完整轨迹。
>
> 可以看到工具名称——通知解析或材料检查，输入摘要、执行状态和时间。支持按工具类型筛选，点击行展开查看完整的输入输出。
>
> 这个功能对排查问题和审计追溯非常有价值。


## 十二、管理员用户管理（30 秒）

**画面**：退出学生 → 登录管理员 → 用户管理

**操作**：
1. 退出，登录 `admin` / `123456`
2. 查看用户列表
3. 编辑用户角色
4. 添加新用户

**讲解**：

> 最后看一下管理员视角。管理员登录后进入独立的管理面板。
>
> 可以查看全部注册用户，按关键词搜索，编辑用户角色（学生 / 教师 / 管理员），以及添加或删除用户。
>
> 删除操作采用**逻辑删除**——数据库记录标记 `is_deleted = 1`，数据不物理删除，符合数据安全规范。这是通过 **MyBatis-Plus 的 @TableLogic** 注解实现的。


## 十三、技术总结 & 收尾（30 秒）

**画面**：系统 Logo 或架构图特写

**讲解**：

> 总结一下这套系统的技术亮点：
>
> - **前端**：Vue 3 Composition API + Element Plus + Vite 8，单页应用，支持 Mock 离线开发
> - **后端**：Spring Boot 3.5 + MyBatis-Plus + Flyway 数据库迁移
> - **AI 集成**：DashScope qwen-turbo 做文本解析和材料审核，qwen-vl-plus 做 PDF OCR 降级
> - **数据库**：MySQL 8.0，10 张业务表，触发器 + 存储过程保障实时进度计算
> - **部署**：Docker 多阶段构建，免费部署到 Render + Aiven MySQL
>
> 谢谢观看！
