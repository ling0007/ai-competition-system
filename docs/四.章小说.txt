# 第一章 陨落的天才

“斗之力，三段！”测验魔石碑上刺眼的五个大字，让少年萧炎唇角勾起一抹自嘲。周围顿时炸开嘲讽：“果然又在原地踏步！”“昔日的天才，怎么落魄成这样？”

萧炎落寞地回到队伍最后。接着，萧媚测出七段斗之气，引来羡慕。而萧薰儿——紫裙少女，气质如清莲——走到碑前：斗之气九段，高级！测验员赞叹她是萧家百年内第二人，第一人正是已褪去光环的萧炎。

薰儿却未在意周围目光，安静走到萧炎面前，恭敬道：“萧炎哥哥。”

萧炎苦涩：“我现在还有资格让你这么叫吗？”

薰儿柔声说：“你说过，要能放下才能拿起。我相信你会重新站起来。”

萧炎只是苦笑，转身离去。薰儿快步追了上去。

# 第二章 斗气大陆

月夜，山崖之巅。萧炎心中藏着一个秘密：他不属于这个世界，而是从地球穿越而来。这片大陆以斗气为主，功法分天、地、玄、黄四阶。他本因灵魂强大而成为天才，却在三年前斗气莫名消失，沦为废物。

“我草你奶奶的！”萧炎对着夜空咆哮。发泄过后，他抚摸着母亲留下的黑色古戒。

父亲萧战从树林中走出，叹道：“一年后成年仪式，若斗之气达不到七段，只能将你分配到家族产业中。这是族规，我也无法改变。”

萧炎微笑着安慰父亲，心中却明白毫无机会。他抬头喃喃：“我会尽力的。”手指上的黑色古戒，忽然亮起一抹微弱毫光，眨眼便逝。

# 第三章 客人

翌日，大厅。三位长老竟没给萧炎准备座位，族中少年发出讥笑。萧薰儿淡淡开口：“萧炎哥哥，坐这里吧。”长老们竟无人敢说话。

来客是云岚宗的人。老者为七星大斗师，身旁青年是五星斗者，而那位冷艳少女——三星斗者。薰儿低声道：“她叫纳兰嫣然——你指腹为婚的未婚妻。”

萧炎脸色一变。薰儿解释：纳兰嫣然被云岚宗宗主收为弟子，如今有了改变命运的力量，此次是来解除婚约的。

萧炎袖中手掌紧握：“如果自己现在是斗师，谁又敢如此践踏？”

薰儿轻轻按住他的手：“她若如此行事，日后必然后悔。”

对面，纳兰嫣然不断示意，那位老者终于站了起来。

# 第四章 云岚宗

葛叶老者起身，尴尬地说出退婚之意，并愿以三枚聚气丹作为补偿。大厅中窃窃私语，三位长老眼中满是讥讽。

纳兰嫣然平静地看着萧炎，仿佛这一切理所当然。

萧炎缓缓开口：“纳兰小姐，你要退婚，我答应。不过——今日你以云岚宗之势当众逼我萧家退婚，这口气我记下了。三十年河东，三十年河西，莫欺少年穷！”

纳兰嫣然脸色微变，仍淡淡道：“希望你的本事配得上你的口气。”

萧炎转身写下休书，重重拍在桌上：“不是你要退婚，是我萧炎，休了你！”

满堂皆惊。纳兰嫣然脸颊涨红，冷冷道：“希望你不会后悔。”

萧炎淡淡一笑：“我从不后悔。”

纳兰嫣然愤然离去。萧战望着儿子的背影，眼眶泛红。

萧炎走出大厅，身后传来长老的冷哼。萧薰儿轻声喃喃：“萧炎哥哥，你说过，要能放下才能拿起。今日你放下了，来日，你一定拿得起。”

月光下，少年孤单的背影渐行渐远。手指上的黑色古戒，再次亮起一抹微弱的毫光。
